# Fotos de la galería

Deja aquí las fotos de la colla (`.jpg`, `.png`, `.webp` o `.avif`) y aparecerán
solas en la sección «Galeria», ordenadas por nombre de archivo
(`01-drakafesta.jpg`, `02-korrebars.jpg`…). Astro las redimensiona y las
convierte a WebP al publicar, así que se pueden subir en buena calidad.

Mientras la carpeta no tenga fotos, la galería muestra las ilustraciones de
`src/assets/brand`.
